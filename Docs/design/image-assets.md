# 图片资产与 Roblox 映射

## 工作区

底部提供“UI 资产 / 图片资产 / 输出”。UI 资产只列“永久UI / 项目UI”，图片资产只列“永久图片 / 项目图片”，分别记住当前库。永久UI沿用空占位，项目UI沿用工程界面文件列表。

图片列表直接显示当前库的卡片，不提供搜索栏、导入按钮或本地文件拖入导入。每张卡片使用统一的 124×76 矩形预览框，图片保持比例完整显示，不撑开预览框；卡片显示名称和“仅本地 / 已配置 ID”。点击图片即在工作台现有右侧属性面板展示图片属性；点击节点树或画布节点切回节点属性，底部不另建属性表单。节点的“定位图片资产”切到图片页并选中对应图片。图片可应用到当前节点或插入新 ImageLabel；拖入画布在 ScreenGui 下创建图片节点。

图片属性提供预览、名称、标签和唯一 Roblox 资源 ID。永久与项目图片使用相同字段，不提供默认/覆盖配置。接受正整数字符串或 `rbxassetid://…`，存储统一为完整引用。未保存属性切换页签、库、图片或节点时提示放弃修改。属性点击保存即落盘，不进入界面撤销历史；应用和插入图片节点进入文档历史。

图片列表不显示常驻操作按钮。资产卡片右键弹出菜单，提供「应用到选中节点」「插入图片节点」「打开目录」「复制 ID」。菜单在点击外部、按 Escape、滚动或切换库时关闭。「打开目录」通过系统文件管理器打开图片所属库的 `image-assets` 目录，目录不存在时创建；内置图片属于永久库。图片以 Data URL 保存于清单，目录并非原始图片所在位置。「复制 ID」复制完整 `rbxassetid://…` 引用；未配置 ID 时禁用。

## 数据和解析

资产使用稳定内部字符串 ID，平台当前固定 Roblox；列表、属性和 MCP 只处理当前支持平台。永久图片保存于 `Runtime/image-assets/catalog.json`，项目图片保存于 `<工程>/image-assets/catalog.json`。新清单使用 version=2，仅含 assets，不改变 project.json。兼容读取 version=1 图片及其自身 robloxId，旧覆盖字段不参与解析，新写入不包含覆盖字段。每个清单最多 100 张、64 MiB，图片沿用 PNG/JPEG/WebP/GIF 与单张 10 MiB 读取限制。清单嵌入图片 Data URL，移动项目不依赖导入源路径；拒绝目录与清单链接、损坏格式，不覆盖损坏清单。

图片节点可附加 `imageAssetId`，仍保存已解析 Image 和嵌入 previewImage 快照，保持单独保存界面的可移植性。编辑器、保存、运行及 MCP 均取图片自身的 robloxId；永久图片的 ID 在项目间共享，项目图片只属于自己的工程。当前库没有该资产时保留文档快照，节点属性明确提示缺失，不删除预览。库存在但未配置 ID 时 Image 为空，只能本地预览。

引用节点的 Image 属性只读，应选中图片资产修改资源 ID，或先解除引用再手动设置。平铺、颜色、透明度和尺寸由节点维护，配置 ID 不重置这些属性。图片引用仍使用文档 version=3 的可选节点字段；旧无引用节点继续支持原有预览图片入口。

## 内置资源

- Stud 透明平铺：稳定 ID `builtin:roblox:stud`，96×96 原透明纹理，默认 Roblox ID `82793028306773`。应用时设置 Tile 和 27×27 Offset，后续可改节点参数。
- 问号占位图：稳定 ID `builtin:roblox:placeholder`，128×128，本项目绘制，无默认 Roblox ID。

来源见 [内置资源说明](../../Editor/src/assets/images/README.md)。内置数据随 App 打包；修改内置图片的 ID 保存到永久库。

## AI 与验证边界

`uie.assets.search` 查询名称、标签、库并分页，返回 robloxId；`uie.assets.get` 返回详情与图片预览；`uie.assets.configure` 保存名称、标签和唯一 robloxId，省略字段保留原值，不支持 projectRobloxId 参数。AI 制作通过 `ui.assets.apply(nodeId, assetId)` 应用同一资产，随 code.execute 整笔支持撤销、dry-run 与失败回滚。制作 VM 不开放文件与网络。资产属性变化使旧 MCP 编辑会话失效，需重新读取状态。

无自动上传、权限查询或 Roblox 导出功能。本地预览、ID 语法正确与配置保存均不能证明审核通过或目标游戏有权加载；配置页明确显示权限未验证。

## 检查

`tests/image-assets.test.ts` 检查单一 ID、永久库共享、项目隔离、旧清单兼容、导入、项目移动、非法 ID、损坏清单、快照与制作应用；`npm run test:assets` 构建并运行图片资产 Electron 冒烟，验证页签分类、无搜索与导入入口、统一矩形预览、共用属性面板、配置、保存重开、画布拖入和 MCP。截图保存在忽略的 test-results 目录，不能代替 Studio 验证。
