# Roblox 静态 UI 编辑

## 当前能力

工程模式通过 `ProjectStrategy` 选择平台规则，当前实现 `RobloxProjectStrategy`。
通用工作台负责文件操作和编辑会话；策略及类型注册表提供节点默认值、属性定义、
层级校验和静态布局。注册表同时供属性面板、文档校验及画布使用。

画布逻辑尺寸固定为 1280×720；缩放、平移和适应窗口只改变显示。
空白处拖动、空格加拖动、中键拖动和普通滚轮用于平移；Ctrl 加滚轮用于缩放。
节点树和画布联动选择。新增、删除、复制、改名、父节点调整、兄弟顺序、移动、
尺寸及属性编辑均进入撤销历史，一次连续画布拖动只提交一条命令。
辅助节点在树上独立显示，通过父节点展示效果；辅助节点不能有子节点。

节点树使用 Roblox Studio 浅色主题原版 16×16 PNG 类型图标，资源随应用打包，来源见
[图标资源说明](../../Editor/src/assets/roblox-node-icons/README.md)。使用单行“类型图标 + 节点名称”，每层缩进 18px，有子节点时显示展开箭头，
悬停显示完整名称和类型。拖拽参考 BlockModelEditor：行上、中、下三等分分别表示
插到目标前、移入目标末尾、插到目标后；前后落点显示横线，移入显示边框。
根节点不可拖动，也不能移到自身或后代；非法父子关系和重复辅助组件不接受落点。
一次拖拽整体移动子树并进入一条撤销命令；移入后的选中节点祖先自动展开。

节点树不显示复制、删除或上下移按钮，顶部编辑菜单保留撤销和重做。
Ctrl+C 复制选中节点的子树快照，Ctrl+V 将快照粘贴到当前选中节点的同级末尾，
Ctrl+D 直接复制当前节点到同级末尾，Delete 删除当前节点。根节点不能复制、删除，
也不能作为同级粘贴的目标。每次粘贴或直接复制都生成新的子树 ID，并遵守层级及组件唯一性校验。
复制快照不进入历史；粘贴、直接复制和删除各进入一条撤销命令，重做恢复相同 ID。
快照仅保存在工作台会话内，不写入系统剪贴板；文本输入控件保留原生复制粘贴和删除行为。

可作为父节点的行在悬停或键盘聚焦时显示右侧“+”，点击展开可添加的节点类型列表，
选择类型直接添加为该行节点的子节点，不依赖当前选中节点；列表过滤非法父子关系和
重复辅助组件。添加后选中新节点并自动展开祖先。点击列表外、按 Escape 或切换界面关闭列表。

## 节点和属性

| 分类 | 节点 |
| --- | --- |
| 根 | ScreenGui |
| 容器 | Frame、ScrollingFrame、CanvasGroup |
| 文本 | TextLabel、TextButton、TextBox |
| 图片 | ImageLabel、ImageButton |
| 外观 | UICorner、UIStroke、UIGradient |
| 布局 | UIListLayout、UIGridLayout、UIPadding |
| 尺寸 | UIScale、UIAspectRatioConstraint、UISizeConstraint、UITextSizeConstraint |

每份文档只有一个 ScreenGui 根；其他可视节点可嵌套。每个可视节点下的同类型
辅助组件最多一个，UIListLayout 与 UIGridLayout 互斥；UITextSizeConstraint
只能放入文本节点。复制子树时所有 ID 重新生成。

常用属性包括 Position、Size、AnchorPoint、Rotation、Visible、ZIndex、LayoutOrder、
背景颜色及透明度、裁剪、文本、字体与对齐、图片资源 ID 与缩放方式，以及各辅助组件
的常用属性。支持属性的完整定义以注册表为准，未知属性拒绝保存和加载。

列表按 LayoutOrder 或名称排序，跳过不可见条目；网格支持换行、方向、单行/列数量
上限和间距。布局控制的子节点禁止直接编辑位置、旋转或通过画布拖动；网格也禁止
直接编辑尺寸。兄弟上下移改变文档顺序，LayoutOrder 不相同时按布局排序规则显示。
网格依据最小尺寸预留跨格区域；尺寸约束超出单元时采用完整边界尺寸，缩放后
在预留区域中居中，其他条目绕开已占用的格子。
宽高比约束遵循 Roblox 默认的 `FitWithinMaxSize`，在原始宽高内收敛，不扩大尺寸。
`UITextSizeConstraint` 仅在 `TextScaled=true` 时约束预览字号。

位置与尺寸使用 UDim2：`{ x: { scale, offset }, y: { scale, offset } }`。
UDim 为 `{ scale, offset }`，Vector2 为 `{ x, y }`，颜色使用 `#RRGGBB`。
UIGradient 首版使用 ColorStart/ColorEnd 和 TransparencyStart/TransparencyEnd
表达首尾关键点；这些是文档格式，后续导出需转换为 Roblox 的序列属性。

## 保存与加载

进入工程时不自动新建或打开界面，中央显示“请打开一个工程”，节点树与节点属性为空，项目UI仅列出已有文件；保存、运行和导入 Roblox 在打开或新建界面后可用。“新建界面”先输入名称，实时显示交互类与接入类名称；取消或未保存提示被取消时保留当前文档。名称按脚本标识符校验，规则见 [交互脚本与接入运行时](ui-runtime.md)。一个工程可保存多个界面。
默认保存位置为 `UIEditorWorkspace/interfaces/<自定义名称>.rbxui.json`，首次保存和
另存为使用原生文件对话框，允许选择其他位置。打开界面使用原生文件选择器，或在
项目UI卡片上右键选择“打开”；项目UI递归列出 `interfaces` 及其子目录内的界面，
卡片名称来自文件名，悬浮提示显示完整路径，同名文件各自保留。扫描不跟随目录或文件
符号链接。工程外保存的文件可通过原生
选择器打开，但不列入项目UI。新建界面显示未保存卡片，保存到工程目录后成为文件资产。
工程的 project.json 仍只描述工程元数据。

项目UI卡片使用与画布共用的静态节点渲染，按比例显示 1280×720 界面缩略图，
不运行脚本、不显示选择框或响应节点交互。当前界面随编辑实时更新，其他界面通过
受限预览接口读取和校验，并解析图片资产；预览不会切换当前文件或修改历史。
损坏文件显示“预览不可用”，不阻断其他卡片。缩略图不写入 UI 文件。

UI 资产目录还提供“模板参考”，是跨工程共用的持久库，存放在编辑器
`ToolRuntime/Runtime/template-references/`，不写入工程目录；测试时跟随
`UI_EDITOR_USER_DATA` 隔离。它复用项目UI的递归列表、文件校验与静态缩略图。
文件菜单、节点右键及库内“保存当前UI为模板参考”保存当前完整文档快照，
同名参考覆盖前确认，不改变当前文件路径或已保存基线。
参考卡片右键“打开副本”先处理当前未保存修改，再加载为未落盘的编辑副本；
对该副本普通保存或“保存为项目UI”不会覆盖参考原件。库文件包含节点、脚本与嵌入图片快照，
不是参数化模板、继承关系或运行逻辑。

“永久UI”存放在 `ToolRuntime/Runtime/ui-assets/`，跨工程共享，复用列表、缩略图
与“打开副本”流程。已保存卡片右键“移动”可选择其他两个资产库，文件移到目标库
根目录并保留原文件名与内容；目标同名时拒绝移动，不覆盖任何一端。
未保存卡片的移动项禁用。移动成功后刷新列表，源文件不再保留。
正在编辑的文件随移动更新保存路径，保留未保存修改、保存基线和撤销历史；
移动本身只搬运磁盘文件，不隐式保存，后续保存写入新位置，不重建旧文件。
移动请求只接受来源库枚举出的普通文件，目标目录由主进程根据库名决定。

文件菜单、节点行右键和未保存 UI 卡片右键提供“保存为项目UI”，将当前完整界面
保存到工程 `interfaces/<界面名称>.rbxui.json`，不是单独保存选中子树。路径由主进程
生成；与当前文件不同的同名目标覆盖前需确认。取消或失败保留当前文档与未保存状态。

文档保存 format=`roblox-ui`、version=3、稳定文档 ID、名称、固定 canvas、root 和 scripts。加载 version=2 时转换脚本结构，不提供 version=1 迁移。
节点保存稳定 ID、className、name、完整 properties 与有序 children。
scripts 只保存交互和测试接入两份类源码，配置和状态由接入类维护，节点通过脚本路径获取，格式见 [交互脚本与接入运行时](ui-runtime.md)。不保存选中状态、视图变换、撤销历史或运行会话。

读取和写入均校验文档与节点字段、属性类型/取值、ID 唯一性、辅助节点关系以及尺寸
约束的上下界。最多 5000 个节点、64 层，文件最多 32 MiB；不支持版本拒绝加载。
主进程使用同目录临时文件加重命名保存；失败清理临时文件，保留旧文件及未保存状态。
实际读写路径来自原生对话框、本会话已打开/保存的文件或主进程列出的工程界面资产。
资产打开请求须匹配所选库目录内的普通 UI 文件，拒绝目录、符号链接和库外路径；
项目库限当前工程 `interfaces`，永久UI与模板参考限对应 Runtime 目录。
读取时仍完整校验界面文档。不接受渲染进程指定保存目标路径。

保存成功以文档内容记录基线，撤销回到该内容时恢复“已保存”。新空文档未落盘但无
修改时不提示丢失；发生编辑后，切换文档、返回 Hub 或关闭窗口提供保存/不保存/取消。
保存失败或取消保存时不继续离开。读取失败或取消选择保留当前文档与历史。
打开或新建成功时重置历史。Ctrl+S 保存，Ctrl+Shift+S 另存为。

## 图片与预览边界

Image 保存 Roblox 资源标识；节点的 previewImage 分别保存本地文件名和图片 Data URL。
预览图嵌入文档，移动工程不依赖原图片路径；支持 PNG/JPEG/WebP/GIF，单张最多 10 MiB。
图片可通过主进程选择并读取，或通过制作 API 附加已经取得的图片 Data URL，不自动上传或访问远程资源。缺失预览图显示占位提示。
图片还可从永久与项目库引用，节点附加 imageAssetId 并保留预览和 Image 快照；单一 Roblox ID、属性入口与 MCP 见 [图片资产](image-assets.md)。引用节点的 Image 由资产解析，解除引用后恢复手动编辑。

编辑模式的按钮和输入框只用于选择；运行模式的 TextButton、ImageButton 支持 Activated，输入框仍不提供运行交互。字体使用本机替代字体，TextScaled
使用静态估算，GroupColor3 使用浏览器混合近似展示。ImageColor3 只乘入实际图片
像素，保留透明度和 Fit 留白；TileSize 支持 Scale/Offset，默认 1×1 Scale，
平铺从左上角开始。旧图片节点缺少 TileSize 时加载补入默认值，文件版本保持 3。
GothamBold 在本机以 Segoe UI 粗体替代。UIStroke 在文本节点上描画文字，在其他节点上画外边框。
UIGradient 分别插值颜色和透明度，并与背景、文字或图片的颜色及透明度相乘；
旋转渐变的中心线控制点落在节点边界上。
ScrollingFrame 通过 CanvasSize 与 CanvasPosition 展示静态滚动区域，位置按原生规则
归整并限制到窗口范围，遵循 ClipsDescendants。横纵滚动条会因对方占用窗口而联动，
长度、端帽和位置采用默认纹理展示，绘制在子节点下方；未实现运行时滚动输入。
这些差异不能作为 Roblox 的精确排版或颜色保证，后续需在 Studio 和设备上验证。
已通过 Studio 对比修复上述渐变、描边、图片、滚动条与网格组合差异；本轮未处理
字体排版、自动字号和 CanvasGroup 复杂混色，也不宣称所有组合逐像素一致。测试范围和证据见
[显示对比测试记录](../../Editor/tests/roblox-display-report.md)。

## 配置数据

测试接入类在自身脚本中定义临时配置，通过 GetUIConfig 提供给交互类，见 [运行规范](ui-runtime.md)。

## 运行时状态

初始模拟状态在测试接入类 Ctor 中定义，动作处理修改状态后调用 RefreshUI；运行结果不写回设计。状态外观编辑器尚未实现。

## Luau 展示与交互

交互类使用 FX.Class 继承 CUIEditorUICompClass，负责通用展示与交互；测试接入子类继承交互类，提供临时配置、状态及动作入口，见 [运行规范](ui-runtime.md)。不提供 Controller、任意 Roblox 服务、动态节点或热更新。

## Roblox 导出与 Rojo

文件菜单提供通过 Toolkit 的一次性导入，包含静态节点、交互基类和共用的公共基类；接入脚本仅用于编辑器预览，见 [Roblox 一次性导入](roblox-import.md)。

## AI 与 MCP

当前通过 MCP 查询能力与节点，在独立制作 VM 执行代码创建或修改文档，执行结果整体支持撤销重做；交互与模拟接入沿用现有类脚本合同。运行、点击、日志、截图、文件边界与工作区见 [MCP 自动化](mcp-automation.md)。
