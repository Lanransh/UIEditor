# 模板风格与项目 AI 工作区

## 工程类型与风格边界

工程类型包维护平台节点、脚本语言、展示与业务接入合同、MCP 制作及验证流程。
风格包维护视觉规范、模板、资源和可选专项技能；不再提供项目 AGENTS.md。
当前只支持 Roblox，不增加其他平台实现或工程类型选择界面。

所有新工程，包括空白和历史模板克隆工程，都拥有独立 AgentWorkspace。
工程公共技能从 ProjectTypes/Roblox 分发；选择风格时再叠加对应视觉包。
工程类型技能与风格技能共同使用，风格不能声明平台未支持的接口或覆盖公共技能。

## 维护源与分发路径

- 平台维护源为仓库 ProjectTypes/Roblox；风格维护源为 TemplateStyles/Roblox/<风格名>。
- 开发版读取维护源；打包版读取应用 resources/ProjectTypes/Roblox 与
  resources/TemplateStyles/Roblox，不依赖 ToolRuntime 的外置 AI 工作区或风格库。
- 两种资源包随应用打包，修改维护源后需重新构建打包才能影响打包版新建工程。
- 公共 AGENTS.md、Docs/、.agents/skills/ 在创建和实际打开工程时同步；相同内容不重写，废弃公共文件清理。
- 风格只在新建时复制到 styles/，之后归项目维护，打开和重开不读取或更新 styles/。
  AGENTS.LOCAL.md 仅缺失时创建，已有内容保留。工程移动后继续使用相对引用。
- ToolRuntime/AgentWorkspace 已退役。旧 Stud 资源、来源与视觉示例保存在
  Docs/references/legacy-roblox-ui，仅作历史参考，不分发为当前项目规范。
- UI_EDITOR_USER_DATA 只重定向运行数据，不改变资源包读取位置。

风格文件夹名作为 ID 和显示名称，说明取 Game-DESIGN.md 首个非空、非标题行。
模板命名与用途由实际文件及规范表达，程序不硬编码窗口和按钮名称。

当前画风 **多彩棋格风格** 从实际 UIEditor 模板取得，保留 7 份独立模板：
SmallWindow、MediumWindow、LargeWindow、Title、CloseButton、
OperationButtonExamples、ProgressBar。不包含用户要求删除的
TemplatePage 展示页；没有修改来源工程原件。
采用鲜明的多彩游戏配色，标题默认红色，可按主题选择红、橙、黄、绿、
蓝、青、紫或粉色，不固定红色。按钮按语义配色；付费购买、充值采用
金黄色 `#FFD633` 与橙色底部压边 `#E58A25`，普通主动作保持亮绿，
标题、按钮和进度使用白字描边；黑色窗口底板与 Stud 平铺纹理保留，
“棋格”不表示改用棋盘格贴图。模板不包含全画布展示背景。
配色与节点结构以实际模板及制作规范为依据。
用户提供截图时默认只参考布局，不沿用原语言或配色；显示文案转为英文，
颜色遵循项目规范，只有用户明确要求参考配色时才参考截图颜色。
此规则随制作包复制到新工程，已有工程的独立提示词不会自动更新。

## 制作包协议

工程类型包必需非空 AGENTS.md。风格包必需非空 Game-DESIGN.md 和至少一份
有效 template-references/**/*.rbxui.json；风格根 AGENTS.md 不复制到工程。
风格可选根 Markdown、assets/、references/、examples/ 和 .agents/skills/，保留子目录。
公共包使用 AGENTS.md、Docs/ 与 .agents/skills/。
技能 SKILL.md 声明有效 name；专项技能从 Game-DESIGN.md 链接，公共技能从平台入口链接。

合并时拒绝重复目标路径、同名技能目录及重复技能 name，不静默覆盖或合并技能内部文件。
包内 Markdown 相对链接独立闭合；不允许绝对本机链接、越界或遗漏资源。
工程类型入口对可选 Game-DESIGN.md 使用存在时读取的约定，不硬链接不存在的风格文件。
HTTP 链接仅作补充资料；App 不下载。复制忽略 node_modules、Git、缓存、构建输出、日志
和临时文件；拒绝符号链接、目录联接及特殊文件。

```text
UIEditorWorkspace/
├─ project.json
├─ interfaces/
└─ AgentWorkspace/
   ├─ AGENTS.md                  # 编辑器维护，不提交
   ├─ AGENTS.LOCAL.md            # 项目维护，提交
   ├─ Docs/                     # 编辑器公共规范，不提交
   ├─ .agents/skills/           # 编辑器技能入口，不提交
   └─ styles/                   # 项目风格，新建时复制，以后不自动更新
      ├─ Game-DESIGN.md
      ├─ templates/
      ├─ assets/、references/
      └─ skills/
```

源风格包保留原布局：template-references/、Game-DESIGN.md、.agents/skills/。
安装时分别映射到 styles/templates/、styles/Game-DESIGN.md、styles/skills/；
Markdown 相对链接随路径调整，模板及二进制资源保持原字节。项目模板读写统一使用 styles/templates/。

图片预览保存在模板 JSON 中，Roblox ID 独立保存；不允许通过 imageAssetId
关联来源工程或全局图片目录，以免后续被来源图片变化覆盖。
需要从项目图片库制作模板时，保存为含 previewImage 与 Image 的独立快照。
模板与资源按字节复制，提示词仅调整相对链接，不重写元数据、类名或设计属性。
源码类的适配由项目 AI 制作新界面时处理，不修改模板原件。

## 新建、校验与失败

### Hub 画风查看

Hub 的“画风库”打开独立只读查看窗口：左侧列出真实封面、名称、数量和说明，
中间按模板相对路径列出全部模板，右侧复用 `DocumentPreview` 展示所选模板。
预览按可见顶层组件的合并范围聚焦，保留周围留白；支持适应窗口及 25%–400%
缩放，小型关闭按钮不再缩在整张空画布中。无可见组件时回退完整画布。
只读预览不选择或拖动节点、不执行脚本、不保存模板，不创建工程和历史记录。

打开及“刷新”重新发现画风并读取磁盘，保留仍存在的画风和模板选择。
模板读取仅接受画风 ID，主进程沿用包、链接、文件格式和资源引用校验，
不接受渲染进程提供任意绝对路径。空库、损坏和读取失败明确展示，可刷新重试。
底部标注“应用画风库”和实际风格目录；开发版和打包版沿用本页既定路径，
不为查看临时改用另一个库。已有工程使用独立副本，不自动同步或覆盖。

### 新建工程

新建始终先显示选择步骤；可选空白工程、整套风格，
风格选项左侧显示真实模板的静态缩略图，沿用 UI 资产的预览渲染，
右侧保留名称和说明。封面取设计规范中首先链接的模板；
没有模板链接时按模板相对路径排序取首个，不固定任何风格的模板名。
预览不执行脚本、不修改模板；不可用风格显示占位并保持禁选。
有历史时可选兼容的历史模板克隆。单选来源互斥，
主进程只接受单个风格 ID 或已登记的历史路径，
不接受渲染进程提供任意来源绝对路径或两种混合来源。

对话框显示风格描述、模板数量及缺失文档/坏模板/访问错误；
坏风格保留可见但禁选。库读取错误明确展示，仍可创建空白工程。
历史克隆仅从来源工程复制模板；平台公共入口和技能来自当前工程类型包，不复制来源风格提示词。

选择父文件夹后独占创建工程目录。有效目标已存在时仅询问打开；
无效目标提示更换位置，不改已有模板、规范或 AgentWorkspace。
新建时重新读取并校验工程类型包和可选风格包，检查冲突，先取得完整快照再复制；
文件使用独占创建。失败仅清理本次创建的文件及空目录，不递归删除用户内容。
清理受权限等阻碍时报告具体未清理路径，不谎称成功回滚。

工程内容不依赖全局库，项目移动后仍能使用相对引用；
修改项目不回写风格库，修改库不更新已建工程。
实际打开前同步公共提示词，并补齐 Git 忽略规则；不覆盖 AGENTS.LOCAL.md 或 styles。
只读校验工程及列出最近工程不触发同步。同步失败时不激活工程，显示具体错误，可修复后重试。
编辑器不包含通用旧工作区迁移逻辑，也不自动修改 Git 索引。
project.json 保持既有版本和字段，不保存源工程本机路径。

## 项目 AI 工作入口

AgentWorkspace/AGENTS.md 是编辑器维护的入口，明确要求读取 AGENTS.LOCAL.md。
制作使用 roblox-ui-authoring，编写 Luau 同时使用 roblox-luau-standards；具体规范位于 Docs/。
存在 styles/Game-DESIGN.md 时读取风格规范及其明确链接的专项技能，不依赖 styles/skills 自动发现。
没有选定风格也能使用平台能力，不强制套用默认蓝色窗口、签到示例或多彩棋格主题。

公共制作技能指导通过 MCP 读取工程模板结构与截图，确认当前工程身份、节点能力和运行限制，
再制作、运行测试、截图检查、保存并重开。模板查询使用 library/target，不将图片查询当模板查询。
展示类声明数据字段、必需及可选覆写方法与动作；模拟接入实现同一契约，真实业务独立接入。
当前未实现的 API 或适配开关不能因写入设计方案就作为已支持能力使用。

风格技能只补充实际视觉制作方法和检查，普通代码流程不重复维护。
UIEditor 模拟状态不能作为真实资格、支付或发奖依据；App 检查不证明 Studio/设备显示。

## 验证

`tests/template-styles.test.ts` 覆盖发现、损坏、访问受限、平台与风格独立复制、技能冲突、空白工程工作区、
独立性、移动、已有目标保护、相对引用、链接拒绝、复制失败回滚、
开发/打包的单一读取路径、外置旧副本隔离，以及更新后新工程使用新版、
已有工程风格保留原快照。agent-workspace.test.ts 验证公共规范更新、LOCAL/styles 保护、
重复同步不改写、Git 忽略与链接路径拒绝。
`npm run test:styles` 构建后运行相关单元测试、真实风格选择与历史克隆冒烟；
`npm run test:styles:packaged` 验证已打包应用的同一流程。
可使用 UI_EDITOR_PACKAGE_OUTPUT/ UI_EDITOR_PACKAGED_EXECUTABLE 隔离打包验证，
不替换正在运行的用户应用。
