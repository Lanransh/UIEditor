# 展示与业务接入

| 层 | 职责 |
| --- | --- |
| CUIView | 刷新、显隐、适配、动作转发及连接清理 |
| 页面 View（source） | 继承 CUIView，绑定节点与事件，用 Config/State 渲染界面，用 EmitUIAction 发送动作和稳定业务 ID |
| 模拟接入（integration） | 继承 View，提供同一契约的模拟数据与动作结果，仅在编辑器运行 |
| 游戏接入 | 在 Generated 之外继承 View，提供真实数据、订阅、资格校验、请求防重及结果 |

游戏接入只实现契约开放的方法。展示行为有缺陷时，在 UIEditor 修复 View、用模拟数据验证并重新导出。

## 随 View 导出的接入契约

在 source 文件头或 Render 附近写分节注释，让游戏接入者只读 View 就能完成以下工作。按页面实际情况填写，模拟专用字段留在 integration。[完整脚本示例](script-contract-example.md)

- **准备数据。** 列出 Config/State 的嵌套字段、类型、单位、必填项、可选默认值、枚举和字典键对应的业务 ID。给一份可用于首次刷新的最小完整数据；说明加载、空列表和后续更新方式。
- **接入生命周期。** 按执行顺序写明挂载、准备依赖、绑定、首次显示、订阅刷新、重开和销毁。默认 GetUIConfig/GetUIState 读取 self.Config/self.State，RefreshUI 调用 Render(GetUIState())。
- **实现接口。** 区分必须实现、条件覆写、继承、仅调用及 View 内部方法。列出实际签名、参数和返回值、调用时机及 Super 顺序。简单值直接用字段；页面专用查询和格式化方法给出默认行为，必需方法未实现时明确报错。
- **处理状态与动作。** 说明状态优先级、展示属性、点击许可、动作名及 payload。锁定状态仍可能允许点击查看原因。点击只发请求，界面收到业务结果后刷新；不添加“领取中”等临时状态。公共 OnUIAction 默认无操作，有业务动作的页面应声明接入处理方法。

## 通用打开与关闭动画

窗口使用 Show()/Hide()，Render 只更新内容。若需要记录窗口状态，在 OnShow/OnHide 同步。覆写 Show/Hide 时调用父方法，关闭动画结束前保持窗口主体可见。

| View 类字段 | 默认行为 | 何时设为 false |
| --- | --- | --- |
| OpenAnimation | 游戏端整页围绕屏幕中心缩放，联动背景模糊和相机 | 常驻 HUD 需要立即显隐 |
| ScreenAdaptation | 随可用尺寸变化，按 1280×720 等比居中 | 页面自行管理设备布局，如自行适配的 MainUI |

两个开关独立，在创建实例前设定并注明关闭原因。局部组件沿用父容器布局。游戏动画由 FCUICompClass / FC.UIAnim 执行，App 预览立即显隐。

## 动态展示

- 固定内容直接绑定。文字、图片和进度就地更新，其他属性保留设计值。进度 Fill 左锚并填满高度；target > 0 时宽度取 math.clamp(current/target, 0, 1)，否则显示空条及占位，保留原始数据。
- 动态图片由 View 根据业务数据替换，缺图时清除旧图并显示占位。静态缺图保留可预览的设计节点，资源到位后直接替换。记录节点、用途、替换方式及真实 Roblox 资源 ID；本地预览与游戏资源分别核验。[图片设置](editor-api.md)
- 运行能力以 get_capabilities 为准。实时倒计时、复杂动画、3D 展示及游戏模块依赖需单独核实。

### 滚动位置与刷新

刷新时保留列表和 CanvasPosition，由滚动容器处理内容缩短后的边界。仅在内容尺寸变化时更新 CanvasSize，仅在初始化或显式导航时定位。

### Templates 与运行时克隆

1. 在界面内建立隐藏的 Templates Frame，保存可编辑的行或卡片原型。布局、图片和按钮放在原型中，显示容器单独设置。
2. 新增业务 ID 时克隆原型，设置名称和数据，挂入显示容器并设 Visible=true。Clone 不复制事件；每个实例绑定一次，点击读取当前业务 ID。已有 ID 只更新属性与顺序。
3. 局部组件从传入子树查找节点。用 TrackConnection 托管连接，用 TrackCleanup 登记清理并保存返回的 release。移除 ID 时先释放组件，再由创建者销毁克隆根；空列表清理全部实例并保留原型。
4. 隐藏期间保留实例；销毁时释放剩余资源。覆写 Dtor 时先清理自身资源，再调用父方法。
