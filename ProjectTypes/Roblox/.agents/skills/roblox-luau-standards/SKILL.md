# Luau 编码规范

编写脚本前读取 [编码规范](../../../Docs/coding-standards.md) 和
[脚本数据契约](../../../Docs/presentation-contract.md)，按实际接口实现并验证。
涉及文本显示时读取 [UI 文本与翻译接口](../../../Docs/text-localization.md)，
采用各文件顶层 TranslationTexts 和 Text.Tr(definition, arguments)。
