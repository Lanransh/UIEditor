# 共享永久图片

`image-assets/catalog.json` 保存永久图片的稳定 ID、名称、标签、嵌入图片及
唯一 Roblox 资源 ID。此目录随 UIEditor 仓库提交，不包含 API Key、本机路径
或上传会话。内置图片的默认内容仍随 App 打包，对其配置的修改保存到此清单。

在电脑 A 上传成功后，提交清单的变更；电脑 B 拉取同一版本，即可使用相同
图片和 Roblox ID，无需重新上传。项目图片仍提交到对应游戏工程，不放在这里。
不要只提交 UI 文件而漏掉本次修改的图片清单。

开发版与默认 `ToolRuntime/UIEditor-win32-x64/` 打包版读取仓库根目录下这份
共享库。重新打包不会覆盖它；搬移打包应用时应保留这个目录与应用的相对层级。

首次读取会兼容迁移旧 `ToolRuntime/Runtime/image-assets/catalog.json` 中尚未
存在于共享库的图片；共享库已有记录优先，不会被另一台电脑的旧 ID 覆盖。
旧清单保留，迁移标记仅写入旧 Runtime，不提交。
