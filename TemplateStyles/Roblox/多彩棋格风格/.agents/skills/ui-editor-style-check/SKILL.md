# 多彩棋格制作与视觉检查

先读 [设计规范](../../../Game-DESIGN.md)。平台制作、代码、模拟测试与保存流程由
工程类型技能提供；本技能只补充风格制作与视觉检查。

## 模板制作

按用途选择最小合适窗口，实际读取模板结构和属性；保留窗口、标题、关闭组件和按钮
语义色。独立组件只复制所需子树，跳过展示说明，不重复添加已有标题或关闭组件。
视觉节点保留在设计态；Stud 使用单张透明图片平铺，不逐个生成凸点。
节点命名使用 PascalCase，按钮 Btn、文字 Txt、可见表面 Img、透明容器 Box。
进度使用完整模板，通过数据更新填充比例，不制作多个静态进度版本。

## 视觉检查

- 截图参考：默认只对照布局；未明确要求参考配色时，使用项目主题色与按钮
  语义色，不沿用截图颜色。明确要求参考配色时说明对应调整，其他样式仍遵循本风格。
- 文案：截图中的原语言已转成英文，业务含义不变；静态文字、交互脚本和
  模拟数据驱动的各状态文案均为英文，不中英文混用。
- `uie.nodes.find/get`：关键组件完整，实际点击节点类型正确；
  字号/Font 与本项目规范匹配，普通文字可编辑且不小于 16px。
- 展示背景：没有 `BackgroundImg`，也没有改名后覆盖全画布的同类背景；
  窗口、标题和按钮自身的底板正常保留，不误删组件视觉。
- 样式：逐项核对已读模板，标题默认红色，也可按主题选择规范内其他鲜明颜色，
  同步压边色；关闭绿色、主动作亮绿、付费购买与充值金黄色（`#FFD633`，
  橙色压边 `#E58A25`）、取消灰绿、卸载橙红。
  标题、按钮和进度保留白字与文字描边、黑色外轮廓和 Stud 平铺。
  项目实际模板修改后不强套旧参数，明确差异。
- 图片：预览保存在节点中，Image 是独立 Roblox ID；不依赖本机路径，
  不遗漏资源，不逐个创建 Stud 凸点，普通文本不转图片。
- 层级：组件底板/纹理/高光压边/文本依次呈现，文字不被遮挡；
  几何与 ZIndex 以模板为准，不新增外投影、发光或模糊。
- 裁剪：按设计规范“裁剪与缩放亮缝”核对；无隐藏溢出内容需求的贴边
  装饰按钮使用 `ClipsDescendants=false`，并检查装饰和文字没有越界遮挡。
  不把 UICorner 当作子节点圆角裁剪，不一律关闭列表或滚动容器的裁剪。
  Studio 可用且本次允许验证时，检查原始比例及“适应窗口”的亮缝、边角和文字；
  未执行时明确标注，不能用 App 截图代替 Roblox 验证。
